# DUSK PROTOCOL · 더스크 프로토콜

능력 드래프트 기반 **P2P 3D 택티컬 FPS** (1v1 / 2v2). 브라우저에서 바로 실행되며, **게임 서버가 없어 운영 비용이 0원**입니다.

- 시작 시 3회 능력 드래프트 — 보유한 능력은 다음 단계 강화 카드로 등장 (Ⅰ 기본 → Ⅱ 강화 → Ⅲ 각성), 특정 조합은 시너지 발동
- 세트 다전제 라운드제 (5판 3선승 / 7판 4선승 / 9판 5선승) — 상대 팀 전원 처치 시 라운드 즉시 종료
- 헤드샷, 거리별 피해 감소, 방어구 관통, 반동 패턴, 이동/공중 탄 퍼짐
- 맵의 골드 코인 · 처치 · 어시스트 · 라운드 결과로 골드를 모아 구매 단계에 무기/방어구/능력 강화 구매
- WebRTC P2P (호스트 = 플레이어 중 한 명), 빈 자리는 AI 봇이 채움, 오프라인 봇 연습 모드

## 빠른 시작

```bash
npm install
npm run dev        # http://localhost:5173
```

빌드 / 검사:

```bash
npm run build      # tsc --noEmit + vite build → dist/
npm run lint       # ESLint (typescript-eslint)
npm run preview    # 빌드 결과 미리보기
```

## 무료 배포

`dist/`는 순수 정적 파일입니다(`base: './'` 상대 경로). 아래 중 아무 곳에나 올리면 됩니다.

- **GitHub Pages**: 저장소에 푸시 → Settings → Pages → Source를 *GitHub Actions*로 설정. `.github/workflows/deploy.yml`이 lint → build → 배포까지 자동 수행합니다.
- **Cloudflare Workers**: 저장소를 연결하고 배포 명령은 기본값 `npx wrangler deploy` 그대로 둡니다. 루트의 `wrangler.jsonc`가 `npm run build` 실행 후 `dist/`를 정적 에셋으로 올리므로 빌드 명령 칸은 비워 둬도 됩니다.
- Cloudflare Pages / Netlify / Vercel / itch.io: 빌드 명령 `npm run build`, 출력 폴더 `dist`.

## 멀티플레이 방법

1. 한 명이 **방 만들기** → 5자리 방 코드(또는 초대 링크 `?room=CODE`)를 친구에게 전달
2. 친구는 **방 참가**에서 코드 입력 (초대 링크로 들어오면 자동 입력)
3. 호스트가 모드(1v1/2v2)·세트·봇 설정 후 **게임 시작**

### 왜 서버 비용이 0원인가

| 단계 | 사용 기술 | 비용 |
| --- | --- | --- |
| 정적 호스팅 | GitHub Pages 등 | 무료 |
| 시그널링(접속 중개) | PeerJS 공개 브로커 `0.peerjs.com` | 무료 (자체 서버 없음) |
| NAT 통과 | Google / Cloudflare 공개 STUN | 무료 |
| 게임 트래픽 | 브라우저 간 WebRTC DataChannel 직접 통신 | 무료 |

- 토폴로지: 스타형. 호스트 브라우저가 라운드·경제·피해 판정의 권한을 갖고, 각 클라이언트는 호스트와 두 개의 채널로 연결됩니다.
  - `rel` (신뢰·순서 보장): 사격/피격/구매/드래프트 등 이벤트
  - `fast` (비순서): 30Hz 위치 상태 ↑ / 22Hz 스냅샷 ↓ (110ms 보간)
- 히트 판정은 *사수 기준(favor the shooter)* 으로 클라이언트가 계산하고, 호스트가 무기 최대 피해·인벤토리·생존 여부로 검증합니다.
- 수류탄은 고정 타임스텝 결정론적 시뮬레이션이라 투척 초기값만 전송합니다.

### 알려진 한계

- TURN 서버가 없으므로 양쪽이 모두 대칭형 NAT(일부 기업망·모바일 핫스팟)이면 연결이 실패할 수 있습니다. 필요하면 **설정 → 네트워크(고급)** 에 직접 운영하는 TURN 서버를 `turn:host:3478|user|pass` 형식으로 입력하세요.
- 호스트가 나가면 경기가 종료됩니다(호스트 마이그레이션 없음). 경기 중 나간 클라이언트는 봇이 대신합니다.
- 데스크톱(키보드·마우스) 전용입니다.

## 게임 규칙

### 라운드 흐름

`로비 → 능력 드래프트(3회) → [구매 단계 → 전투 → 라운드 종료] × N → 결과`

- 전투 100초. 상대 팀 전원 처치 시 즉시 종료, 시간 종료 시 남은 체력 합이 높은 팀 승리(동률 무승부)
- 전투 20초 경과 시 중앙 신호탑에 **대형 골드(350G)** 출현
- 사망하면 구매한 주무기·방어구를 잃고, 생존하면 다음 라운드로 유지

### 경제

### 능력 증강 트리 (Ⅰ 기본 → Ⅱ 강화 → Ⅲ 각성)

- 드래프트 카드는 **신규 능력(Ⅰ)** 또는 **보유 능력의 다음 단계(Ⅱ/Ⅲ)** 입니다. 강화 가능한 능력이 있으면 매 드래프트에 그 강화 카드가 최소 1장 보장됩니다.
- 능력 슬롯은 Q · E · F 3칸. 넓게(능력 3개) 갈지, 깊게(한 능력을 Ⅲ 각성까지) 갈지가 선택입니다.
- 구매 단계에서 골드로도 다음 단계 강화 가능 (Ⅰ→Ⅱ 1000 / Ⅱ→Ⅲ 2400)
- 재충전이 있는 능력은 전투 중 시간이 지나면 충전이 1회씩 돌아옵니다. 각 단계 효과는 누적됩니다.

| 능력 | Ⅰ 기본 | Ⅱ 강화 | Ⅲ 각성 |
| --- | --- | --- | --- |
| 섬광탄 | 0.8초 신관, 실명 2초 | **순간 섬광** — 0.5초 팝 플래시, 충전 2 · 재충전 25초 | **제압 섬광** — 실명된 적 4초간 능력 사용 불가, 재충전 18초 |
| 연막탄 | 반경 4.4m · 12초 | **신속 연막** — 충전 2 · 재충전 22초 | **맹독 연막** — 연막 속 적 초당 10 독 피해(방어구 무시), 충전 3 · 재충전 16초 |
| 파편 수류탄 | 최대 85 피해 · 반경 5m | **진탕 파편** — 맞은 적 2.5초 이속 −35%, 충전 2 | **집속탄** — 폭발 후 자탄 4개 연쇄 폭발(각 40) |
| 에너지 방벽 | 내구도 350 · 폭 3m | **강화 방벽** — 내구도 550 · 폭 3.8m, 재충전 30초 | **반사 방벽** — 방벽을 쏜 적에게 피해 20% 반사, 충전 2 |
| 질풍 대시 | 6m 돌진 | **연속 대시** — 충전 2 · 재충전 12초 | **칼바람** — 처치 시 대시 충전, 대시 후 1초간 이동 탄퍼짐 없음, 충전 3 |
| 나노 치유 | 3초간 40 회복 | **나노 장갑** — 55 회복 + 방어력 15, 재충전 30초 | **불사 프로토콜** — 라운드당 1회 헤드샷이 아닌 치명상을 HP 1로 버티고 자동 치유 |
| 정찰 펄스 | 반경 28m 적 노출 2.5초 | **반향 펄스** — 1.8초 뒤 같은 자리에서 재탐지, 충전 2 | **약점 분석** — 노출된 적 받는 피해 +15%, 반경 44m |
| 광학 위장 | 3.5초 투명, 사격 시 해제 | **무음 위장** — 위장 중 발소리 없음, 충전 2 | **잔상** — 사격해도 위장 유지(0.6초만 드러남), 재충전 30초 |
| 무한 탄창 | 5초간 탄약 무한 | **과열 사격** — 연사 +10% · 6.5초, 재충전 35초 | **흡혈 탄환** — 준 피해의 30% 체력 흡수, 충전 2 |
| 아드레날린 | 5초간 이속·연사·재장전 ↑ | **투쟁 본능** — 사용 즉시 재장전, 재충전 35초 | **폭주** — 지속 중 처치 시 지속 초기화 + 체력 35 회복 |

### 시너지 (두 능력을 함께 보유 시 자동 발동)

| 정찰 펄스 + 섬광탄 | 표적 섬광 | 내 섬광에 실명된 적 3초간 노출 |
| 나노 치유 + 에너지 방벽 | 재생 방벽 | 방벽 4m 내 아군 초당 10 회복 |
| 파편 수류탄 + 정찰 펄스 | 추적 파편 | 폭발 지점 12m 내 적 3초간 노출 |
| 광학 위장 + 무한 탄창 | 유령 사격 | 무한 탄창 중 사격해도 위장이 풀리지 않고 잠시 드러남 |
| 나노 치유 + 아드레날린 | 투지 | 치유 시 아드레날린 3초 발동 |

## 기술 구성

- **렌더링**: three.js r186 (WebGL2) — PBR, PCF 소프트 섀도우, ACES 톤매핑, Unreal Bloom, GTAO(최고 품질), SMAA, 커스텀 컬러 그레이딩(비네트·색수차·피격·섬광 잔상·연막)
- **에셋 0개**: 모든 텍스처(콘크리트·골판지 컨테이너·목재·체커플레이트 등 알베도/노멀/ORM), 총기·캐릭터 모델, 사운드가 런타임에 절차적으로 생성됩니다.
- **오디오**: WebAudio 합성 총성/발소리/폭발, HRTF 3D 공간음향, 거리 기반 공기 흡수, 컨볼루션 리버브
- **물리**: AABB 스윕 캐릭터 컨트롤러(계단 오르기, 지면 스냅, 앉아 점프), 결정론적 투척물
- **AI**: 캐릭터 이동을 직접 시뮬레이션해 만든 내비게이션 그래프 + A*, 반응 시간·조준 오차·버스트 제어·능력 사용

```
src/
  core/      설정, 입력, 유틸, 상수

  game/      호스트(권한 로직), 클라이언트, 플레이어, 봇, 내비, 무기, 능력, 아바타, 뷰모델
  net/       PeerJS 네트워크 계층, 프로토콜 정의
  audio/     절차적 오디오 엔진
  ui/        HUD, 드래프트, 상점, 로비, 메뉴, 점수판 등
```
